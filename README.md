# Goblin's Gold Hoard

Goblin's Gold Hoard is a Dungeons & Dragons reskin of the Munder Difflin multi-agent harness.

## Core Narrative Mapping

- **Munder Difflin** → **Goblin's Gold Hoard** (coordination system)
- **Office floor** → **Goblin Warren** (shared workspace)
- **Michael (GOD agent)** → **Gruk** (Goblin Warlord/Overseer)
- **Agent memory** → **Goblin Grimoire**
- **Router/mailbox** → **Messenger ravens and couriers**
- **Terminal output** → **Scribe's scrolls**
- **Skills catalog** → **Spell compendium**

## Fantasy Multi-Agent Setting

Adventurers, goblins, gnomes, and kobolds coordinate raid plans from a winding goblin warren.  
Tasks are framed as treasure raids, dungeon heists, and quest dispatches while preserving the same underlying harness behavior.

## Visual Theme

- **Primary**: `#2D5016` (deep goblin green)
- **Accent**: `#FFD700` (treasure gold)
- **Secondary**: `#4B0082` (deep arcane purple)
- **Neutral**: `#708090` (stone gray)

UI flavor uses scroll-like panels, dungeon iconography, and warren-inspired environment language.
