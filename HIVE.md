# Goblin Warren Operations (HIVE)

## Warren Model

The Goblin Warren is a shared multi-agent workspace where each adventurer executes assigned quests and reports to Gruk.

## Message Flow

1. Gruk issues a quest edict.
2. Messenger ravens deliver assignments to adventurers.
3. Adventurers consult the Goblin Grimoire for prior spellcraft and raid notes.
4. Results are returned as Scribe's scrolls.

## Quest Types

- Treasure raid planning
- Vault heist execution
- Trap disarm analysis
- Lore extraction and documentation
- Perimeter scouting and reconnaissance

## Role Safety

Paladin-class agents focus on defensive checks and secure-by-default behavior during quest execution.
