# Goblin's Gold Hoard Design

## Theme Goal

Replace "The Office" framing with a Dungeons & Dragons goblin-warren aesthetic while keeping harness behavior unchanged.

## Terminology System

- Coordination layer: **Goblin's Gold Hoard**
- Shared runtime space: **Goblin Warren**
- Overseer agent: **Gruk, Goblin Warlord**
- Memory store: **Goblin Grimoire**
- Message router: **Messenger ravens/couriers**
- Command output: **Scribe's scrolls**
- Skills inventory: **Spell compendium / magic scroll library**

## Visual Language

- Primary: `#2D5016`
- Accent: `#FFD700`
- Secondary: `#4B0082`
- Stone neutral: `#708090`

Panels and status surfaces should evoke parchment, carved stone, and treasure-map styling.

## Character Framing

Agents are represented as chaotic dungeon-adjacent characters (goblin, gnome, kobold, halfling, and adventurer classes) rather than office staff.
